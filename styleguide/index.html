Steps

Horizontal ladder (≥768px) and .steps--vertical.

light

  1. Specify

    Every open question gets decided one at a time, with a recommended answer.

  2. Direct

    An orchestrator splits the work into lanes; a fresh reviewer scores each change.

  3. Prove

    Test output and screenshots, never summaries.

  1. Brief

    One session prompt per ticket, with hard rules and a definition of done.

    89 session prompts · docs/agents

  2. Fresh review, 9/10 or it loops

    A new subagent every round, so it has no memory of writing the code and no stake in the score. At most five rounds.

    docs/agents/review-loop.md:21-30

Findings

light

  1. Run the counter, don’t enforce the cap

    The daily order cap shipped switched off, but the counter ran from day one, derived from real orders on demand so there is no stored number to drift.

    includes/class-capacity.php:2-17

  2. The cut-off is a minute, not a day

    Lead time became lead days plus a cut-off time (2 days, 12:00 pm), and the order day flips at the cut-off’s exact minute.

    includes/helpers.php:907-911
