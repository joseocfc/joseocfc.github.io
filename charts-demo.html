Chart system

Ten charts, one grammar

Every figure on this site is drawn by one small D3 library from the real data files: a validated eight-slot palette read from the design tokens, hairline grids, direct labels, a tooltip, a table and a download on every chart. This page exists to show that grammar holding across sources and forms, so it mixes the build’s git history with the first week of orders and a public dataset from Epoch AI. Commit hours, commit types, lines by area and co-authorship by model are on the process page.
